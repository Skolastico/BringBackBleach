Daily image journal / 30 October 2026 / A test we decided not to use

Our latest attempt recovered more tiny detail in a test image, but side-by-side review found no clear visual improvement. It also missed our preset target for improving the larger shapes, so we are keeping the previous version for now.

The original DVD picture can look soft. Restoring texture is useful only if faces, outlines and motion still look right. A score can improve even when a person cannot see a worthwhile change.

We compared two versions of the same action frame and rejected the newer attempt. We are now looking for better matched scenes before another small experiment.
